손으로 그린 흑백 스케치북
모바일 와이어프레임

색을 지운다. 검정 먹선 + 흰 종이 단 두 값으로 승부한다. 귀여움은 컬러가 아니라 둥글고 삐뚤한 손선·두들 표정·굵은 흑백 대비에서 나온다. 강조가 필요하면 검정 반전 블록 하나로 끝낸다 — 심플함의 핵심은 "색을 더하지 않는 것".

1선을 떨게 한다

모든 박스는 ::before 가상요소에 테두리를 그리고 SVG feTurbulence + feDisplacementMap(#dw) 변위 필터를 걸어 테두리만 손그림처럼 떨리게 한다. 콘텐츠 텍스트는 왜곡되지 않는다. 모서리 border-radius도 4곳을 다르게 줘서 정원·직선을 없앤다.

2그림자는 단색 오프셋

블러 그림자 금지. 4px 5px 0 #17150F처럼 번지지 않는 검정 오프셋 그림자만 쓴다 — 종이에 스티커를 붙인 듯한 물성. 채움은 회색 대신 검정 빗금(해칭) repeating-linear-gradient(45deg)으로 표현해 흑백만으로 밀도를 만든다.

3색 대신 굵기·반전

강조색이 없으므로 위계는 선 굵기·크기·검정 반전 블록으로만 만든다. 손글씨(Gaegu)는 제목·버튼·라벨에, 산세리프(Pretendard)는 긴 본문에. 두들 얼굴·하트·반짝이 모티프가 정보 없는 공간을 귀엽게 채운다.
