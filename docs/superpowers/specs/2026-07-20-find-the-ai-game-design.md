# "AI를 찾아라" 게임 — 디자인 스펙

- 날짜: 2026-07-20
- 상태: 승인됨 (브레인스톰 완료 + 2026-07-20 사용자 지시 반영)
- 선행: 파티 가로 게임 월드(2026-07-16), 어몽어스(Phase 6d)
- 자매 스펙: `2026-07-20-game-world-visual-upgrade-design.md` (비주얼 강화 — 별도 플랜)

## 1. 개요

기존 어몽어스 게임을 **"AI를 찾아라"**로 변형한다. 파티(인간 4~8명)가 게임을 시작하면
**AI 임포스터 2명**이 가짜 페르소나로 잠입한다. 인간은 **전원 크루** — 채팅과 행동을
근거로 누가 AI인지 추리해 투표로 찾아낸다. AI는 LLM으로 채팅하며 인간인 척 연기하고,
맵에서 움직이며 킬을 노린다.

> **핵심 규칙(2026-07-20 사용자 지시): 임포스터는 AI 전용이다. 인간 유저 중에서
> 임포스터를 뽑는 일은 절대 없다.** 기존 among.service의 인간 임포스터 선출 로직은 제거.

## 2. 확정 요건

| 항목 | 결정 |
|---|---|
| 포지셔닝 | 어몽어스를 변형·대체 — among 자산(세션/회의/투표/스윕/리댁션) 위에 구축 |
| 역할 | 인간 = 전원 크루. 임포스터 = AI 봇 **2명 고정**(`AMONG_AI_COUNT`) |
| 인원 | 매칭 무변경(인간 4~8) + AI 2 = 총 6~10 (풀 파티 시 "남녀 10명") |
| 게임플레이 | 어몽 풀세트 유지(태스크/킬/신고/긴급/투표) + **주기 자동 회의** 추가 |
| 승리 | AI 전원 추방 → 인간 승 / 생존 인간 ≤ 생존 AI → AI 승 / 태스크 완료 → 인간 승 (기존 매핑) |
| AI 채팅 | LLM 필수(운영). 페르소나 연기, 회의 변명·의심, 플레이 중 잡담 |
| AI 경계 | 게임 세션 안에만 존재 — 프로포즈/DM/멤버시트/신고 대상 불가, 종료 시 정체 공개 |

## 3. 게임 룰 상세

- 시작(자동/수동 무변경): 인간 전원 role="crew" + AI 페르소나 2명 role="impostor"로 잠입.
  AI 페르소나 = 한국 이름·나이·직업·말투 프리셋 풀에서 추출(내장 상수, 세션별 랜덤).
- **주기 자동 회의**: `AMONG_AUTO_MEETING_MS`(기본 120000) 경과 시 스윕이 회의 소집.
  `AmongMeetingView.reason`에 `"auto"` 추가 — 클라 라벨 "정기 투표"(Vote 아이콘).
  신고·긴급 회의는 그대로. 회의 해소 후 타이머 리셋.
- 태스크: 인간 크루만 보유(기존 tasksPerCrew). AI는 태스크 없음(기존 임포스터와 동일)
  — 태스크 승리 분모는 기존 "생존 크루 소유" 규칙 그대로.
- 킬: AI만 수행. 쿨다운·시체·신고 규칙 무변경.
- 리댁션: 기존 유지(役 role은 ended까지 null). `isBot`/`isAi`는 **플레이 중 절대 미노출**.
  ended 스냅샷에서만 `AmongPlayerView.isAi: true` 세팅 → 결과 화면 "AI" 배지.
- RoleReveal: 인간은 항상 크루 카드 — 카피 "파티에 AI 2명이 숨어 있어요. 채팅으로
  찾아내세요!". 임포스터 리빌 화면은 인간에게 나올 수 없음(역할이 랜덤이 아니므로).

## 4. AI 액터 (백엔드 `AiImpostorService`)

- 기존 PartyGateway 1s 스윕 lifecycle에 봇 틱 편입. 파티별 advisory lock 하에 상태 전이.
- 봇 상태는 `GameSession.state`에 저장(페르소나, 목표점, nextChatAt, 킬 유예) — 재시작 내성.
- **이동**: 스테이션 순회 랜덤워크(PARTY_MAP.stations 셔플 목표, stepToward 시뮬).
  서버가 `party:moved`(profileId=AI) 브로드캐스트 — 클라 onMoved가 미지 ID 자동 등록이라
  렌더 경로 무변경. 이동 빈도 = 인간 유사(≤10Hz 스로틀).
- **킬**: 쿨다운 완료 + 인간 근접(world 계량) 시 확률 트리거. 회의 해소 직후 유예.
  같은 방에 다수 인간이면 회피(목격 리스크 연기) — 단순 휴리스틱. 확률·유예·반경
  상수값은 구현 플랜에서 확정(테스트로 고정).
- **투표**: 회의마다 LLM에 최근 채팅+생존자 목록을 주고 투표 대상 선택(자기·동료 AI 제외).
  LLM 실패 시 랜덤 인간. 투표 타이밍도 랜덤 지연(즉시 몰표 방지).
- **채팅**: LLM 호출로 발화 생성 → `party:message` 형태로 브로드캐스트(DB 미저장 —
  senderId FK 회피; 게임 중에만 유의미. 히스토리 리로드 시 사라짐 허용).
  - 플레이 중: 60~90s 랜덤 간격 잡담(1문장).
  - 회의 중: 1~2회 발화(변명/의심/맞장구). 타이핑 지연 시뮬(글자수 비례).
  - LLM 컨텍스트 = 인메모리 링버퍼(파티별 최근 채팅 30개 — party:chat 수신 시 축적,
    단일 인스턴스 전제) + 게임 상황 요약 + 페르소나 프롬프트.
- 봇 틱 예외는 삼킴(게임 진행 우선) — advisory lock + partial unique가 최종 방어.

## 5. LLM 연동

- 기존 OpenAI-compat 클라이언트(`LLM_API_URL`/`LLM_MODEL`) 재사용, 전용 시스템 프롬프트
  (페르소나·짧은 한국어 구어체·정체 은닉 지시·금칙: 자기 정체/시스템 언급 금지).
- 응답 길이 캡(120자), 게임당 호출 상한 `AMONG_AI_LLM_MAX_CALLS`(기본 60 — 초과 시 침묵/템플릿).
- 호출은 파티별 직렬 큐, 타임아웃 5s → 템플릿 폴백 대사(내장 풀).
- **필수 게이트**: `AMONG_AI_REQUIRE_LLM`(기본 true) — LLM 미설정 시 게임 시작 거부
  (`party:error` "AI 게임 준비 중"). dev/CI는 false로 템플릿 폴백 시작 허용(mega-qa·jest 경로).

## 6. 클라이언트 변경

1. 이름 해석 폴백: 캐릭터·채팅 발신자 이름을 `party.participants`에 없으면 `among.players`
   name으로 폴백(AI 페르소나 표시).
2. `reason: "auto"` 라벨 + 플레이 중 다음 자동 회의 카운트다운(`nextAutoMeetingAt` 스냅샷 필드).
3. 회의/투표 중 채팅 FAB 노출(토론장 = 채팅). ended·역할리빌만 숨김 유지.
4. 결과 화면: AI 배지(Bot 아이콘) — `isAi`는 ended 스냅샷에서만 존재.
5. RoleReveal 크루 카피 교체(§3).
6. **게임 에러 토스트**: `party:error` 메시지를 파티 화면에 표시(QA 발견 — 현재 무시되어
   '다시하기' 인원 부족 시 무반응으로 보임).

## 7. 게임 밖 경계

- AI profileId는 합성 ID — Profile 테이블에 없음: 프로포즈/DM/신고/차단이 구조적으로 실패(404).
- 어몽 중 ActionPad엔 프로필 버튼이 없어 멤버시트 진입 불가(기존 동작). 로비 복귀 시
  AI는 프레즌스에 없어 posRef 클린업으로 소멸.
- 파티 채팅 히스토리에 AI 발화 미저장 — 게임 밖 잔재 없음.

## 8. env

`AMONG_AI_COUNT`(2) / `AMONG_AUTO_MEETING_MS`(120000) / `AMONG_AI_REQUIRE_LLM`(true) /
`AMONG_AI_LLM_MAX_CALLS`(60) / `AMONG_AI_CHAT_MIN_MS`(60000) / `AMONG_AI_CHAT_MAX_MS`(90000).
기존 among env·LLM env 유지. `AMONG_IMPOSTORS`는 AI 수로 의미 이전(사용처 정리).

## 9. 테스트

- backend jest: 시작 시 인간 전원 crew + AI 2 잠입, isAi 리댁션(ended만), 자동 회의 스케줄,
  봇 킬/투표 휴리스틱(LLM 목), LLM 게이트, 링버퍼. 기존 among 스위트 갱신(인간 임포스터
  전제 테스트 재작성).
- mobile vitest: 이름 폴백 순수 함수, 카운트다운 계산.
- mega-qa: `AMONG_AI_REQUIRE_LLM=false` 환경에서 기존 어몽 섹션을 AI 게임 흐름으로 갱신
  (인간 킬 체크 → AI 킬 관찰/강제 경로로 대체).
- 실 LLM 수동 스모크(대화 품질·비용 확인).
