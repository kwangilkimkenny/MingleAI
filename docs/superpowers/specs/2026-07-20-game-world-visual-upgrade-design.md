# 게임 월드 비주얼 강화 — 디자인 스펙

- 날짜: 2026-07-20
- 상태: 승인됨 (2026-07-20 사용자 지시: "진짜 게임처럼 캐릭터나 맵 디자인" — 현행은 스틱피겨·빈 사각형 수준)
- 방향 확정: **두들 라인아트 컨셉 유지 + 밀도 대폭 강화** (스타일 전환·외부 에셋 기각)
- 자매 스펙: `2026-07-20-find-the-ai-game-design.md`

## 1. 목표

파티 게임 월드(`PartyWorld`/`PartyMapArt`/`DoodleCharacter`)를 "진짜 게임" 수준의
시각 밀도로 끌어올린다. 잉크 라인아트 + 코랄 포인트라는 앱 아이덴티티는 유지하되,
현행의 도식적 표현(스틱피겨, 라벨 없는 워블 사각형)을 손그림 일러스트 수준으로 교체.

원칙: 색 절제 유지(잉크 + 포인트 1-2곳), `doodle-path.ts` 시드 지터(결정적 — 재렌더에
끓지 않음), react-native-svg 네이티브 호환(feTurbulence 금지), 이모지 금지.

## 2. 캐릭터 (`DoodleCharacter` 리디자인)

- **체형**: 스틱 라인 → 볼륨 있는 몸통(상의 실루엣 path + 하의), 머리 비율 크게(치비 2등신).
- **개성 변주(시드 = profileId 해시, 결정적)**:
  - 헤어 6종(숏컷/단발/포니테일/파마/투블럭/버즈) — 잉크 path.
  - 상의 4종 실루엣(티셔츠/후드/셔츠/원피스) + 옷 디테일 라인(주머니/스트링/카라).
  - 표정: 눈 3종 × 입 3종 조합(DoodleFace 변주 확장).
  - 포인트: 캐릭터당 1곳만 accent 계열 힌트(예: 후드 스트링·리본) — "화면당 primary 1개"
    규칙은 CTA 기준이므로 소형 의상 포인트는 accentSoft/accentFill 사용.
- **애니메이션(phase 기반 순수 계산 유지)**:
  - 걷기: 팔·다리 2관절 스윙 + 몸통 기울임 + 보빙. 정지: 미세 숨쉬기(느린 sin).
  - 방향 플립 유지. "나"는 이름표 강조(현행) + 발밑 소프트 링.
- **유령**: 반투명 + 물결 치맛단 + 부유 애니(느린 상하). **시체**: 누운 실루엣 + X눈 +
  잉크 얼룩 그림자.
- 크기: 현행 34~56px 스케일 유지. SVG 노드 수 캐릭터당 ≤25(8인 성능 예산).

## 3. 맵 (`PartyMapArt` 리디자인)

- **바닥**: 우드 플랭크 라인(성긴 가로줄 + 짧은 이음선, 낮은 opacity) — 러그 영역은
  패턴 채움(hatchSegments 재사용), 무대는 보드 라인.
- **가구 일러스트화**(전 종 디테일):
  - 바: 카운터 + 스툴 2 + 병 3 + 잔, 상판 해칭.
  - 테이블: 원탁 + 의자 2 + 컵·접시 소품.
  - 소파: 쿠션 분할선 + 팔걸이 + 앞 러그 힌트.
  - DJ 부스: 턴테이블 2 + 믹서 노브 + 케이블 라인, 옆 스피커 스택.
  - 무대: 마이크 스탠드 + 스포트라이트 원뿔 라인(낮은 opacity).
  - 화분: 화분 무늬 + 잎 클러스터(몬스테라풍 잎 3-5장).
- **환경 소품(비충돌 장식 — PARTY_MAP에 `deco` 레이어 추가, 충돌 데이터 무변경)**:
  벽 몰딩 라인, 창문 1-2개, 액자, 스트링 라이트(천장 곡선 + 전구), 바닥 잉크 얼룩.
- **그림자**: solid 가구 아래 하드 오프셋 잉크 그림자(doodle.shadow 문법) — 부유감 제거.
- **마커**: 태스크 스테이션 = 반짝임 라인 + 코랄 링(현행 사각형 대체), 밸런스 스테이션 =
  DJ 부스 네온 힌트.

## 4. 구현 형태

- `PartyMapArt` 내부를 가구별 서브컴포넌트로 분리(`furniture/Bar.tsx` 등 — 파일당 하나,
  본체는 배치만). 정적 memo 유지(레이아웃 크기 변화에만 재렌더).
- `DoodleCharacter`도 파츠 함수 분리(hair/outfit/face) — 시드 → 파츠 선택은 순수 함수로
  `src/lib/character-look.ts`(vitest 대상: 결정성·분포).
- 충돌·좌표·소켓 로직 무변경 — 순수 렌더 교체. `PARTY_MAP` 스키마는 `deco` 배열(선택
  필드)만 추가(백엔드 무영향).
- 성능 예산: 맵 SVG 총 노드 ≤400, 초기 렌더 1회(memo), 캐릭터 리렌더는 기존 rAF 틱 경로.

## 5. 검증

- tsc/prettier/vitest(character-look) + 웹 스크린샷 육안(로비/어몽/유령/시체/8인 밀집).
- 저사양 안드로이드 실기기 프레임 체감은 런북 §7에 항목 추가.
