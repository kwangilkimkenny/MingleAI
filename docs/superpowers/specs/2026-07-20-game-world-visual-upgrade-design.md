## 1. 목표

파티 게임 월드(`PartyWorld`/`PartyMapArt`/`DoodleCharacter`)를 "진짜 게임" 수준의
시각 밀도로 끌어올린다. 잉크 라인아트 + 코랄 포인트라는 앱 아이덴티티는 유지하되,
현행의 도식적 표현(스틱피겨, 라벨 없는 워블 사각형)을 **귀여운** 손그림 일러스트 수준으로 교체.

원칙: 색 절제 유지(잉크 + 포인트 1-2곳), `doodle-path.ts` 시드 지터(결정적 — 재렌더에
끓지 않음), react-native-svg 네이티브 호환(feTurbulence 금지), 이모지 금지.

## 0. 화면 방향 + 프레임 제거 (2026-07-20 추가 — 페이즈 1)

- **가로 타이밍**: 가로 전환을 파티 화면이 아닌 **매칭 시작 시점**으로 앞당긴다.
  `useLandscapeLock`을 `app/(app)/matching.tsx`에도 적용 — 홈에서 "매칭 시작" 탭 →
  `/matching` 진입 즉시 가로 → 파티까지 가로 유지. 홈·탭바·설정 등 나머지는 세로.
  매칭 화면(대기·실패·에러·취소 상태) 레이아웃을 가로에 맞게 재배치(중앙 정렬 유지,
  좌우 safe inset). 루트 `_layout` PORTRAIT_UP 기본 lock은 그대로.
- **게임 월드 프레임 제거**: `PartyWorld`의 `floor`에서 `borderWidth`/`borderColor`/
  `borderRadius` 삭제 → 월드가 레터박스 안을 꽉 채우는 **풀블리드**. 상단바
  `borderBottom` 구분선 제거(반투명 배경만으로 분리). 바닥 경계는 §3의 우드 플랭크가
  담당. 조이스틱·액션패드는 월드 위 오버레이 유지.
- **범위 한정**: 어몽 오버레이 카드(회의·결과·리빌)·채팅·멤버시트·밸런스 모달의 두들 잉크
  테두리는 **유지**(브랜드 정체성 — 제거 대상은 게임 월드 프레임뿐). §3의 "floor 사각
  테두리" 개념은 폐기 — 우드 플랭크 바닥이 가장자리까지 풀블리드로 경계 역할.

## 2. 캐릭터 (`DoodleCharacter` 리디자인) — 볼드 마커 두들 + 귀여움

> **2026-07-21 방향 전환(사용자: "어몽어스 이미지 퀄리티 정도는 나와야 한다"):** 치비-휴먼
> (헤어/상의/표정 조립)을 폐기하고 **어몽어스 크루메이트** 실루엣으로 재구현했다. 콩 몸체 +
> 앞상단 글래스 바이저(하이라이트 streak) + 뒤 백팩 + 짧은 다리 2개. 볼륨은 **cel 셰이드
> 3톤**(본색 + `shade()`로 파생한 하단 코어 섀도우 + 상우 하이라이트, 콩 실루엣 clipPath 클립).
> 슈트 색: 나=코랄(accent), 타인=팔레트 파생 웜 뉴트럴 6종(코랄은 "나" 전용). `character-look`의
> `hair`만 남겨 크루메이트 머리 소품(안테나/캡/리본/꽃/헤드밴드/파티콘)으로 매핑(outfit/eyes/mouth는
> 미사용 — 백로그 정리). 유령=반투명 물결 크루메이트, 시체=반쪽 콩+뼈. 아래 §2 원문은 폐기된
> 치비 방향의 역사적 기록. ⚠️ rn-svg `<Path>`는 x/y prop 무시 — 위치는 `transform="translate()"`로.

**아트 방향(2026-07-20 사용자 레퍼런스 "이런 스타일이 두들아트이다" — Chanoir/Chansia풍
볼드 마커 두들):** 굵고 균일한 검정 마커 아웃라인, 솔리드 블랙 채움 실루엣, 크고 단순한
표정, 통통 둥근 폼. **얇은 라인 금지 — 마커펜처럼 두껍게.** 순수 흑백이 지배적, 코랄은
브랜드용으로 극히 절제(볼터치 정도만). 참고 특징:
- 굵은 잉크 아웃라인(현행 2.6 → **size 비례 굵게, `inkW ≈ max(3.5, size*0.09)`**,
  머리/몸통 외곽은 더 굵게 `size*0.1`).
- 일부 폼은 솔리드 블랙 실루엣("나" 캐릭터 머리는 이미 잉크 채움 — 이 대비를 유지·강조).
- 큰 표정: 땡그란 눈(굵은 원/점+하이라이트), ^^ 반달눈, 점코 옵션, 단순 입.
- 손그림 워블(doodle-path 시드 지터) — 삐뚤빼뚤 자신감 있는 선.

**핵심 목표: "귀엽고 두껍고 확실한 두들".** 아래 레버를 모두 적용한다.

- **체형(치비 비율)**: 스틱 라인 → 머리 큰 2등신(머리:몸 ≈ 1:1). 둥근 몸통 실루엣 path
  (각지지 않게), 짧고 통통한 팔다리(**굵은 마커 라인**, 끝 `strokeLinecap="round"`),
  손발은 작은 원. 전체 실루엣이 동글동글.
- **큰 얼굴·큰 눈**: 얼굴이 캐릭터 면적의 절반. 눈은 크고 굵은 원/점 + 하이라이트 점(작은
  흰 점)으로 반짝임. 볼터치(accentFill 연한 코랄 원 2개) — 유일한 코랄 포인트.
- **개성 변주(시드 = profileId 해시, 결정적)**:
  - 헤어 6종(숏컷/단발/포니테일/곱슬/투블럭/바가지) — 잉크 path, 둥근 실루엣.
  - 상의 4종(티셔츠/후드/멜빵/원피스) — 둥근 어깨선.
  - 표정: 눈 3종(점눈/반달눈/땡그란눈) × 입 3종(미소/오/일자) 조합.
  - 포인트: 캐릭터당 1곳만 accent 계열(볼터치 또는 후드 스트링/리본) — accentSoft/accentFill.
- **애니메이션(phase 기반 순수 계산 유지)**:
  - 걷기: 팔·다리 스윙 + 통통 튀는 보빙(살짝 과장) + 몸통 기울임. 정지: 느린 숨쉬기 sin.
  - 방향 플립 유지. "나"는 이름표 강조(현행) + 발밑 소프트 그림자 타원.
- **유령**: 반투명 + 물결 치맛단 + 부유 애니(느린 상하), 표정 유지(귀여운 유령).
  **시체**: 누운 실루엣 + X눈 + 잉크 얼룩 그림자.
- 크기: 현행 34~56px 스케일 유지. SVG 노드 수 캐릭터당 ≤28(귀여움 디테일 반영 상향, 8인 예산).

## 3. 맵 (`PartyMapArt` 리디자인)

- **바닥**: 우드 플랭크 라인(성긴 가로줄 + 짧은 이음선, 낮은 opacity) — 러그 영역은
  패턴 채움(hatchSegments 재사용), 무대는 보드 라인.
- **가구 일러스트화**(전 종 디테일):
  - 바: 카운터 + 스툴 2 + 병 3 + 잔, 상판 해칭.
  - 테이블: 원탁 + 의자 2 + 컵·접시 소품.
  - 소파: 쿠션 분할선 + 팔걸이 + 앞 러그 힌트.
  - DJ 부스: 턴테이블 2 + 믹서 노브 + 케이블 라인, 옆 스피커 스택.
  - 무대: 마이크 스탠드 + 스포트라이트 원뿔 라인(낮은 opacity).
  - 화분: 화분 무늬 + 잎 클러스터(몬스테라풍 잎 3-5장).
- **환경 소품(비충돌 장식 — PARTY_MAP에 `deco` 레이어 추가, 충돌 데이터 무변경)**:
  벽 몰딩 라인, 창문 1-2개, 액자, 스트링 라이트(천장 곡선 + 전구), 바닥 잉크 얼룩.
- **그림자**: solid 가구 아래 하드 오프셋 잉크 그림자(doodle.shadow 문법) — 부유감 제거.
- **마커**: 태스크 스테이션 = 반짝임 라인 + 코랄 링(현행 사각형 대체), 밸런스 스테이션 =
  DJ 부스 네온 힌트.

## 4. 구현 형태

- `PartyMapArt` 내부를 가구별 서브컴포넌트로 분리(`furniture/Bar.tsx` 등 — 파일당 하나,
  본체는 배치만). 정적 memo 유지(레이아웃 크기 변화에만 재렌더).
- `DoodleCharacter`도 파츠 함수 분리(hair/outfit/face) — 시드 → 파츠 선택은 순수 함수로
  `src/lib/character-look.ts`(vitest 대상: 결정성·분포).
- 충돌·좌표·소켓 로직 무변경 — 순수 렌더 교체. `PARTY_MAP` 스키마는 `deco` 배열(선택
  필드)만 추가(백엔드 무영향).
- 성능 예산: 맵 SVG 총 노드 ≤400, 초기 렌더 1회(memo), 캐릭터 리렌더는 기존 rAF 틱 경로.

## 5. 검증

- tsc/prettier/vitest(character-look) + 웹 스크린샷 육안(가로 매칭 화면·풀블리드 월드·
